# 안테나 통합 문서 작성

`antenna-orchestrator` MCP 서버가 붙어 있어야 한다. 서버는 **LLM 을 부르지 않는다** —
값·표·그림·절 구성은 전부 결정론이고, 당신이 쓰는 것은 `PROSE` 마커 **사이**뿐이다.

## 시작 전에

리소스 `orch://guide` 를 읽는다. 절대 규칙 넷이 거기 있다. 읽지 않고 시작하면 반드시 반려된다.

## 절대 규칙 넷

1. **숫자를 타이핑하지 않는다.** 값은 `{{v:키}}` 참조로만 쓴다. 카탈로그에 없는 값은
   문서에 쓸 수 없고 계산해서 만들 수도 없다.
2. **`|역할` 을 건드리지 않는다.** 골격이 `{{v:<키>|band_lo_ghz}}` 를 주면 `<키>` 만 바꾼다.
   역할과 키가 어긋나면 키를 바꾼다 — 역할을 바꾸지 않는다.
3. **`PROSE` 마커 사이에만 쓴다.** 표 · 제목 · 주석 · 대장은 결정론 산출이다.
4. **행렬 표의 행을 건드리지 않는다.** 이미 키가 박힌 칸은 템플릿의 일부다.

## 표준 순서

```
orch_status()                      환경이 성립하는가 · 원장 정본이 하나인가
discover_sources("<원천 폴더>")     폴더 안에 안테나가 몇 개인가
run_pipeline("<원천 폴더>", product="<제품>")
run_report(run_id)                 무엇이 나왔나 · 무엇이 비었나
document_brief(run_id)             ← 여기부터 당신 차례
submit_document(run_id, markdown)  통과할 때까지 위반만 고쳐 다시
package_run(run_id)                통과본을 산출 폴더로
```

`orch_status()` 의 `ok` 가 `false` 면 거기서 멈추고 사유를 사용자에게 전한다.
원장 후보가 여럿이거나 데이터가 지워질 자리에 쌓이려 하면 그렇게 나온다 — **도구가 고르지 않는다.**

## 문서를 쓸 때

`document_brief(run_id)` 가 셋을 준다 — 골격 · 카탈로그 · 서술 지침.

1. 골격의 `<키>` 를 카탈로그의 키로 바꾼다. 한 줄의 이름·값·판정·출처는 **같은 키**를 가리킨다.
2. `PROSE` 마커 사이에 소견을 쓴다.

서술 규율:

- 숫자를 쓰지 않는다. 값은 이미 위 표에 있다 — 표를 가리키는 말로 쓴다.
- 표에 있는 것을 되풀이하지 않는다. **표가 말하지 못하는 것**을 쓴다 — 값들이 서로
  어떻게 얽히는지, 무엇을 뜻하는지, 무엇이 빈지.
- 확인되지 않은 것을 단정하지 않는다. 근거가 없으면 "확인되지 않았다"고 쓴다.
- 시뮬레이션값과 측정값을 같은 말로 부르지 않는다. 레인은 절 제목이 정해 두었다.
- 계산값을 성능이라고 부르지 않는다. **배열인자는 빔패턴이 아니다.**

## 반려되면

`violations` 만 고쳐 다시 낸다. 종류별 대처는 리소스 `orch://quickstart` 에 표로 있다.

| 종류 | 고치는 법 |
| --- | --- |
| `unsubstituted_ref` | `<키>` 를 카탈로그 키로 채운다 |
| `undefined_key` | `catalog_lookup` 으로 실재하는 키를 찾는다 |
| `role_mismatch` | **키를 바꾼다**(역할을 바꾸지 않는다) |
| `bare_number` | 숫자를 참조로 바꾸거나 문장에서 뺀다 |
| `template_modified` | 골격 원문으로 되돌린다 |
| `prose_unwritten` | 마커 사이를 쓴다 |

## 값이 없을 때 — 물어본다

문서 마지막에 **업데이트 필요** 대장이 선다. 공백은 세 종류다.

- **선언** — 아는 사람이 말하면 그만이다. `declare_gaps(run_id)` 로 목록을 확인하고
  **사용자에게 묻는다.** 답을 들으면 `declare_set` 에 넣는다.
- **반입** — 파일이 들어와야 한다. 무엇이 필요한지 알리고 기다린다.
- **도구** — 도구가 아직 못 읽는다. 무엇이 갖춰져야 하는지 알린다.

★ 사용자가 알려준 값을 **문서에 직접 적지 않는다.** `declare_set` 으로 넣고
`run_pipeline` 을 다시 돌린다 — 그래야 값이 출처와 함께 실린다.
다시 돌리지 않고 `document_brief` 를 부르면 낡은 카탈로그를 받는다(응답의 `stale` 이 알려 준다).

## 하지 않는 것

- 판독 못 하는 포맷에 파서를 만들지 않는다. "판독 불가 + 사유"로 남기고 넘어간다.
- 없는 경계를 지어내지 않는다. 가를 수 없으면 **묻는다**.
- 확정하지 않는다. 도구는 제안하고 사람이 정한다.
- 원본을 고치지 않는다.
