# ★ 플러그인으로 설치했을 때 bootstrap.py 가 ${CLAUDE_PLUGIN_DATA}/venv 에 **동기로** 설치한다.
#   서버가 붙으려면 이 둘이 반드시 있어야 하므로 여기서 먼저·확실히 깐다.

#   - mcp    : 서버 배선(FastMCP). 없으면 서버가 기동조차 못 한다.

#   langgraph 는 **일부러 뺐다.** agent/runtime.py 의 stdlib 대역으로 돌고(I-G),
#   3.14 휠이 없어 설치가 여기서 멈춘다 — 플러그인 기동을 막지 않으려면 넣지 않는다.
#
# ★ mcp 는 1.x 로 고정한다. server.py 는 `mcp.server.fastmcp.FastMCP`(1.x API)를 쓴다 —
#   2.0 은 구조가 바뀌어 그 경로가 사라졌다(mcpserver 등으로 이동). 올리려면 server.py 를 함께 고친다.
